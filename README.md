# pallet

Система контроля наклона палеттов на складе (прототип).

## Что делает

Захватывает фото с двух USB-камер (спереди и сбоку от палетта)
по нажатию ПРОБЕЛ и сохраняет их в папку `captures/`.
Фото предназначены для отправки в нейронку (LLM), которая оценивает
угол наклона палетта и опасность падения.

## Текущий статус (1 спринт)

- Захват: Python + OpenCV на Windows
- 2 камеры, съёмка последовательно (одна за другой)
- Камеры открываются только в момент съёмки (не висят в фоне, не греют USB-шину)
- Промпт для нейронки сохранён в `prompt_pallet_inspection.txt`
- Отправка в нейронку пока НЕ реализована (только сохранение в папку)

## Требования

- Windows
- Python 3.x
- 2 USB-камеры

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
(или без активации: `.venv\Scripts\python.exe -m pip install -r requirements.txt`)

## Запуск

```bash
.venv\Scripts\python.exe camera_capture.py
```

Управление:
- ПРОБЕЛ — снять фото со всех камер
- Q / Esc — выход

Фото сохраняются в `captures/cam{index}_{timestamp}.jpg`.

## Структура

- `camera_capture.py` — основной скрипт захвата
- `prompt_pallet_inspection.txt` — промпт для нейронки (оценка угла в JSON)
- `requirements.txt` — зависимости
- `captures/` — папка с фото (создаётся автоматически)

## Известные ограничения / заметки

- Съёмка занимает ~6 с (последовательно, медленное открытие USB-камер).
  Оптимизация отложена до выяснения скорости нейронки.
- Дешёвые камеры A4Tech стабильно дают 640x480; форсированное разрешение
  (720p) может давать битые кадры. Захват настроен на 1280x960 (факт ~720p).
- В будущем: перенос на Raspberry Pi (смена бэкенда CAP_DSHOW на CAP_V4L2,
  учёт одиночного USB-контроллера Pi 3B+).
